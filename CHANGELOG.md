# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-02-17

### Initialized @mintlify/astro integration

| Feature | Description |
|---------|-------------|
| Astro integration | Syncs Mintlify-style docs into Astro content collections |
| MDX components | Component mapping via `@mintlify/components` |
| Navigation helpers | Sidebar, tabs, footer, and favicon resolution |
| Static assets | Dev server middleware and build-time asset copying |
| Snippets | Snippet resolution and injection into pages |
| Component extraction | Extracts React components from MDX files |
| Raw Markdown | Generates raw Markdown endpoints for each page |
| docs.json API | Reads and exposes docs configuration |
